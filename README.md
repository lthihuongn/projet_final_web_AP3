# JUNIA CV & Talents

Projet de validation réalisé dans le cadre du module **Architecture Web (AP3)**. 
L'objectif est de concevoir une plateforme web dynamique et sécurisée permettant de mettre en relation les étudiants de JUNIA (recherche de stages, alternances, CDI) et les recruteurs partenaires.

---

## Stack Technique

* **Backend :** PHP (architecture modulaire native, sans framework)
* **Database :** MySQL via une interface (utilisation de MAMP)
* **Frontend :** HTML / CSS
* **Asynchronisme :** JavaScript natif (Fetch API) pour la gestion dynamique du catalogue et la sauvegarde automatique en local (via `localStorage`)

---

## Architecture et Bonnes Pratiques

L'arborescence du projet a été rigoureusement structurée pour être claire et maintenable, en conformité avec les consignes du module. Le code respecte les standards de développement web actuels, garantissant ainsi la sécurité, la lisibilité et l'évolutivité de l'application.
